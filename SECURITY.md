# Security and privacy policy

## Supported versions

Security and privacy fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Open a GitHub security advisory for vulnerabilities that could expose resumes, candidate profiles, browsing sessions, credentials, or job-search history. Do not include real personal data in a public issue.

## Data boundary

Treat resumes, candidate profiles, immigration details, job descriptions, and the history ledger as private runtime data. Store them outside the repository or under an ignored local directory. The skill must not request passwords, cookies, session tokens, authorization headers, or complete authenticated requests, and must not bypass authentication, CAPTCHAs, access controls, or platform limits.
